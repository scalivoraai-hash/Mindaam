# World engine

The local renderer is a procedural Three.js scene, not licensed photorealistic 3D coverage. Virtual positions and collectible interactions are server-authoritative. City data and gameplay must remain separate from provider imagery.

Validate keyboard/mobile controls, camera, interaction radius, stale-state reconciliation and a non-WebGL fallback. Cesium/Google licensed tiles, production routing/collision data, streaming LOD and measured mobile performance remain target scope until independently evidenced. Do not populate fake human users.

Status: this document records architecture and validation requirements. See STATUS.md for demonstrated implementation and RELEASE_CHECKLIST.md for acceptance; unrecorded provider/deployment coverage remains pending.
