# Fraud controls

Relevant abuse includes multi-account daily farming, teleport/speed manipulation, QR sharing, GPS spoofing, merchant collusion, webhook spoofing and reward races. Server-side validation and idempotency address parts of these threats but do not constitute a complete fraud system.

Create measurable rules, threshold ownership, evidence minimisation and appeal workflow. Verify rate-limit behaviour across replicas and use anomaly investigations before irreversible sanctions. Do not label a browser location signal as guaranteed real presence or a heuristic flag as proven misconduct.
