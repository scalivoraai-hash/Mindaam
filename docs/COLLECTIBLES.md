# Collectibles

Fruit/gem collection requires authenticated user, correct virtual world location, expiry/availability and server-side claim uniqueness. Server chooses payout, never the client. Local seed content must be visibly marked development.

Test near/far claims, wrong city, expired/depleted content, identical retry and simultaneous users. Mission progression must consume persisted claim events without double payout. Sponsored drop budgets, rarity balancing, abuse resistance and launch content licensing require separate acceptance.
